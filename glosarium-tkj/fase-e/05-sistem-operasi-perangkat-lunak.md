# 05 · Sistem Operasi dan Perangkat Lunak Dasar

> **Fase:** E (Kelas X) · **Elemen CP:** Dasar-dasar teknik jaringan komputer dan telekomunikasi (instalasi dan konfigurasi sistem operasi)
>
> **Ringkasan:** Setelah komputer dirakit, ia butuh sistem operasi. Bagian ini berisi istilah seputar Windows dan Linux: instalasi, partisi, file system, pengguna dan hak akses, perintah dasar terminal, serta perangkat lunak pendukung yang setiap hari dipakai teknisi jaringan.

| No | Istilah | Pengertian | Fungsi / Kegunaan |
|---:|---|---|---|
| 1 | **Sistem Operasi (Operating System / OS)** | Perangkat lunak utama yang mengelola hardware (CPU, RAM, disk, jaringan) dan menjadi tempat aplikasi berjalan. Contoh: Windows, Linux, macOS, Android, iOS, RouterOS. | Tanpa OS, aplikasi tidak bisa berjalan dan pengguna tidak bisa berinteraksi dengan komputer. |
| 2 | **Kernel** | Inti sistem operasi yang berhubungan langsung dengan hardware: mengatur proses, memori, perangkat, dan jaringan. Linux sebenarnya adalah nama kernel. | Menjembatani aplikasi dengan hardware secara aman dan efisien. |
| 3 | **Shell** | Program penerjemah perintah pengguna ke kernel. Di Linux: bash, zsh, sh. Di Windows: Command Prompt (cmd) dan PowerShell. | Menjalankan perintah dan skrip tanpa antarmuka grafis. |
| 4 | **GUI (Graphical User Interface)** | Antarmuka grafis dengan jendela, ikon, dan mouse (Windows Desktop, GNOME/KDE di Linux). | Mudah dipakai pengguna awam. |
| 5 | **CLI (Command Line Interface) / Terminal** | Antarmuka berbasis teks tempat pengguna mengetik perintah. Server dan perangkat jaringan umumnya dikelola lewat CLI karena ringan, cepat, dan bisa diotomasi. | Keterampilan wajib admin jaringan/server. |
| 6 | **Windows (Desktop)** | OS berbayar dari Microsoft yang paling banyak dipakai di PC: Windows 10, Windows 11. Edisi Home, Pro (mendukung join domain, BitLocker, RDP host), Enterprise. | OS klien utama yang akan kamu hubungkan ke jaringan dan domain. |
| 7 | **Windows Server** | Versi Windows untuk server (2016, 2019, 2022, 2025) dengan peran seperti Active Directory, DNS, DHCP, File Server, IIS, Hyper-V. | Mengelola jaringan kantor berbasis Windows secara terpusat. |
| 8 | **Linux** | Keluarga OS open source berbasis kernel Linux yang stabil, aman, gratis, dan mendominasi server, cloud, router, serta Android. | OS utama untuk server jaringan; dipelajari mendalam di Administrasi Sistem Jaringan. |
| 9 | **Distro Linux (Distribusi)** | Paket Linux lengkap dari berbagai pengembang. Keluarga Debian: Debian, Ubuntu, Linux Mint, Kali. Keluarga Red Hat: RHEL, CentOS Stream, Rocky, AlmaLinux, Fedora. Lainnya: Arch, openSUSE. | Memilih distro sesuai kebutuhan: Ubuntu/Debian untuk belajar server, Kali untuk keamanan. |
| 10 | **Debian dan Ubuntu Server** | Debian: distro stabil yang banyak dipakai di UKK dan server. Ubuntu Server: turunan Debian dengan dukungan LTS 5 tahun, dokumentasi melimpah. | Platform paling umum untuk latihan DHCP, DNS, web, mail, FTP server di SMK. |
| 11 | **macOS, Android, iOS, ChromeOS** | macOS: OS komputer Apple berbasis Unix. Android: OS mobile berbasis Linux dari Google. iOS: OS iPhone/iPad. ChromeOS: OS Chromebook berbasis Linux. | Teknisi harus bisa menghubungkan dan menangani beragam OS klien di jaringan. |
| 12 | **RouterOS, IOS, dan Firmware Perangkat Jaringan** | Sistem operasi khusus perangkat jaringan: MikroTik RouterOS, Cisco IOS, Juniper Junos, OpenWrt (open source untuk router rumahan), pfSense/OPNsense (firewall). | Mengelola router/switch/firewall; dipelajari mendalam di Fase F. |
| 13 | **Open Source vs Proprietary** | Open source: kode terbuka, bebas dipakai dan diubah (Linux, LibreOffice). Proprietary: kode tertutup, berlisensi (Windows, Microsoft Office). | Menentukan biaya lisensi dan kebebasan modifikasi. |
| 14 | **Lisensi Perangkat Lunak** | Hak pakai perangkat lunak: OEM (melekat pada perangkat), Retail, Volume (organisasi), Subscription (langganan), GPL/MIT (open source), Freeware, Trial. | Menggunakan perangkat lunak secara legal dan menghindari pembajakan. |
| 15 | **Pembajakan Perangkat Lunak (Software Piracy)** | Memakai perangkat lunak tanpa lisensi sah (crack, keygen, aktivator ilegal). Melanggar UU Hak Cipta dan sering menyisipkan malware. | Teknisi profesional wajib memakai lisensi sah atau alternatif open source. |
| 16 | **Instalasi Sistem Operasi** | Proses memasang OS ke komputer: siapkan media bootable → atur boot order di BIOS → pilih bahasa/zona waktu → buat partisi → salin file → buat user → pasang driver dan update. | Kompetensi dasar TKJ; langkah yang benar menghasilkan sistem stabil. |
| 17 | **Media Bootable dan File ISO** | ISO adalah file citra (image) isi DVD/USB instalasi. Media bootable adalah flashdisk/DVD yang dibuat dari ISO dengan alat seperti Rufus, Ventoy, balenaEtcher, atau Media Creation Tool. | Memulai instalasi OS pada komputer. |
| 18 | **Booting dan Boot Order** | Booting adalah proses komputer menyala hingga OS siap. Boot order adalah urutan perangkat yang dicek BIOS/UEFI (USB, disk, jaringan/PXE). | Mengarahkan komputer agar boot dari flashdisk saat instalasi. |
| 19 | **Boot Loader (GRUB, Windows Boot Manager)** | Program kecil yang dijalankan firmware untuk memuat kernel OS. GRUB di Linux bisa menampilkan menu pilihan OS. | Memulai OS; rusaknya boot loader membuat OS tidak bisa dimuat meski data utuh. |
| 20 | **Dual Boot** | Memasang dua OS (misalnya Windows dan Linux) dalam satu komputer, dipilih saat booting. | Belajar Linux tanpa menghapus Windows; alternatifnya memakai virtual machine. |
| 21 | **PXE Boot (Network Boot)** | Booting komputer melalui jaringan dari server (tanpa disk/USB), memanfaatkan DHCP dan TFTP. | Instalasi OS massal di lab sekolah atau menjalankan thin client. |
| 22 | **Partisi** | Pembagian ruang disk menjadi beberapa bagian logis, misalnya partisi sistem (C:), data (D:), atau di Linux: /, /home, swap. | Memisahkan OS dan data agar instal ulang tidak menghapus file pengguna. |
| 23 | **MBR vs GPT** | Skema tabel partisi. MBR (lama): maksimal 4 partisi primer, disk hingga 2 TB, dipakai BIOS legacy. GPT (baru): hingga 128 partisi, disk sangat besar, dipakai UEFI. | Menentukan cara partisi saat instalasi; salah pilih menyebabkan "Windows cannot be installed to this disk". |
| 24 | **File System** | Cara OS mengatur penyimpanan file di partisi. Windows: NTFS (utama), FAT32 (kompatibel, file maks 4 GB), exFAT (flashdisk besar). Linux: ext4 (utama), XFS, Btrfs. | Menentukan kompatibilitas, batas ukuran file, dan fitur (izin, jurnal). |
| 25 | **Format (Memformat)** | Menyiapkan partisi dengan file system tertentu; data lama terhapus. Quick format hanya menghapus tabel, full format juga memeriksa sektor rusak. | Menyiapkan disk baru atau membersihkan disk untuk instal ulang. |
| 26 | **Swap / Virtual Memory (Pagefile)** | Ruang di disk yang dipakai sebagai "RAM cadangan" saat RAM penuh. Di Linux berupa partisi/file swap; di Windows disebut pagefile.sys. | Mencegah aplikasi crash saat RAM habis, meski lebih lambat dari RAM. |
| 27 | **Direktori, Folder, dan Path** | Direktori/folder adalah wadah file. Path adalah alamat lokasi file: Windows memakai C:\Users\Nama, Linux memakai /home/nama (huruf besar-kecil dibedakan). | Menemukan dan mengelola file lewat GUI maupun CLI. |
| 28 | **Struktur Direktori Linux** | Direktori penting: `/` (root), `/etc` (konfigurasi), `/home` (data user), `/var` (log, web), `/bin` dan `/usr/bin` (program), `/boot` (kernel), `/dev` (perangkat), `/tmp` (sementara), `/root` (home admin). | Admin server harus hafal lokasi file konfigurasi dan log. |
| 29 | **Root dan Administrator** | Root adalah akun berkuasa penuh di Linux; Administrator adalah padanannya di Windows. Akun ini bisa mengubah apa pun, termasuk merusak sistem. | Dipakai hanya saat perlu; bekerja sehari-hari dengan akun biasa lebih aman. |
| 30 | **sudo** | Perintah Linux untuk menjalankan satu perintah dengan hak root dari akun biasa (superuser do), misalnya `sudo apt update`. | Mengurangi risiko dibanding login sebagai root terus-menerus. |
| 31 | **User dan Group** | User adalah akun pengguna; group adalah kumpulan user yang diberi izin bersama. Perintah Linux: `adduser`, `passwd`, `usermod`, `groupadd`. | Membatasi siapa boleh mengakses apa di komputer dan server. |
| 32 | **Permission (Hak Akses) rwx dan chmod/chown** | Setiap file Linux punya izin baca (r=4), tulis (w=2), eksekusi (x=1) untuk pemilik, grup, dan lainnya, misalnya 755. `chmod` mengubah izin, `chown` mengubah pemilik. | Melindungi file konfigurasi dan web dari perubahan/pembacaan tak sah. |
| 33 | **Perintah Dasar Linux** | `ls` (lihat isi), `cd` (pindah direktori), `pwd` (lokasi sekarang), `mkdir`, `rm`, `cp`, `mv`, `cat`/`less` (baca file), `nano`/`vim` (edit), `grep` (cari teks), `find`, `man` (manual), `clear`, `history`. | Modal dasar mengelola server lewat terminal. |
| 34 | **Perintah Dasar Windows (CMD/PowerShell)** | `dir`, `cd`, `md`, `del`, `copy`, `ipconfig`, `ping`, `netstat`, `tasklist`, `shutdown /r`, `sfc /scannow`, `chkdsk`; PowerShell menambah cmdlet seperti `Get-Service`, `Test-NetConnection`. | Menyelesaikan masalah dan otomasi di komputer Windows. |
| 35 | **Package Manager (apt, dnf/yum, pacman)** | Alat pemasang perangkat lunak dari repositori resmi: `apt install` (Debian/Ubuntu), `dnf install` (Fedora/Rocky), `pacman` (Arch). Di Windows ada winget/Chocolatey. | Memasang, memperbarui, dan menghapus program beserta ketergantungannya secara otomatis. |
| 36 | **Repository (Repo)** | Gudang paket perangkat lunak di server (resmi atau mirror lokal seperti kambing.ui.ac.id, kartolo.sby.datautama.net.id) yang dibaca package manager. Daftarnya di `/etc/apt/sources.list`. | Sumber instalasi yang aman; mirror lokal mempercepat unduhan. |
| 37 | **Update dan Upgrade** | Update: memperbarui daftar paket (`apt update`). Upgrade: memasang versi terbaru paket (`apt upgrade`). Di Windows: Windows Update. | Menutup celah keamanan dan memperbaiki bug; kebiasaan wajib admin. |
| 38 | **Patch** | Perbaikan kecil untuk perangkat lunak/firmware yang menutup bug atau celah keamanan tertentu. | Mencegah eksploitasi celah yang sudah diketahui publik. |
| 39 | **Proses (Process) dan PID** | Program yang sedang berjalan disebut proses, masing-masing punya nomor PID. Dilihat dengan Task Manager (Windows) atau `ps`, `top`, `htop` (Linux); dihentikan dengan `kill`. | Memantau beban CPU/RAM dan menghentikan program yang macet. |
| 40 | **Service / Daemon** | Program yang berjalan di latar belakang tanpa tampilan, misalnya layanan web (apache2), SSH (sshd), DHCP. Di Windows dikelola lewat services.msc. | Menyediakan layanan jaringan yang selalu siap tanpa login pengguna. |
| 41 | **systemd dan systemctl** | systemd adalah sistem init modern Linux yang mengelola service; `systemctl start/stop/restart/status/enable nama-service` adalah perintahnya. `enable` membuat service otomatis jalan saat boot. | Mengendalikan layanan server sehari-hari. |
| 42 | **Log File** | Catatan kejadian sistem dan aplikasi. Linux: `/var/log/syslog`, `/var/log/auth.log`, `journalctl`. Windows: Event Viewer. | Sumber utama untuk mencari penyebab error dan jejak serangan. |
| 43 | **Hostname** | Nama komputer di jaringan (misalnya `server-lab`, `PC-01`). Linux: file `/etc/hostname`, perintah `hostnamectl`. Windows: System Properties. | Mengenali komputer dengan nama, bukan hanya IP. |
| 44 | **Environment Variable (PATH)** | Variabel lingkungan yang dibaca program, misalnya PATH berisi daftar direktori tempat OS mencari perintah yang diketik. | Memahami mengapa perintah "tidak dikenali" dan cara menambah program ke PATH. |
| 45 | **Cron dan Task Scheduler** | Penjadwal tugas otomatis. Cron (Linux) memakai baris crontab seperti `0 2 * * * /backup.sh` (setiap jam 02.00). Task Scheduler adalah padanannya di Windows. | Menjalankan backup, pembersihan, atau skrip pemantauan secara rutin tanpa campur tangan manusia. |
| 46 | **Shell Script dan Batch File** | Kumpulan perintah dalam file teks yang dijalankan berurutan: `.sh` (bash) di Linux, `.bat`/`.ps1` di Windows. | Otomasi pekerjaan berulang, misalnya konfigurasi IP massal. |
| 47 | **Text Editor (nano, vim, Notepad++, VS Code)** | Program menyunting file teks/konfigurasi. nano mudah untuk pemula (Ctrl+O simpan, Ctrl+X keluar); vim sangat kuat tetapi perlu dipelajari (i untuk insert, :wq simpan-keluar). | Hampir semua konfigurasi server dilakukan dengan menyunting file teks. |
| 48 | **Kompresi dan Arsip (zip, tar, gz)** | Menggabungkan dan memampatkan file: `zip`/`unzip`, `tar -czvf arsip.tar.gz folder/` (buat), `tar -xzvf` (ekstrak). | Backup, memindahkan banyak file, dan menghemat ruang. |
| 49 | **Backup dan Restore** | Backup: menyalin data/konfigurasi ke tempat lain (disk eksternal, server, cloud). Restore: mengembalikannya saat data hilang/rusak. Aturan 3-2-1: 3 salinan, 2 media berbeda, 1 di lokasi lain. | Satu-satunya penyelamat saat disk rusak, terkena ransomware, atau salah hapus. |
| 50 | **Recovery, Safe Mode, dan Live USB** | Safe Mode: menjalankan Windows hanya dengan driver dasar untuk perbaikan. Live USB: menjalankan Linux langsung dari flashdisk tanpa instal, berguna menyelamatkan data. | Memperbaiki OS yang gagal boot atau mengambil data dari komputer rusak. |
| 51 | **Device Manager** | Alat di Windows untuk melihat semua hardware, status driver, dan perangkat bermasalah (tanda seru kuning). Padanan Linux: `lspci`, `lsusb`, `lshw`. | Memastikan LAN card/Wi-Fi terdeteksi dan drivernya benar. |
| 52 | **Registry (Windows)** | Basis data pengaturan Windows dan aplikasi, diedit dengan regedit. Kesalahan edit bisa merusak sistem. | Menyetel pengaturan lanjutan yang tidak ada di menu; harus di-backup dulu. |
| 53 | **Antivirus / Anti-Malware** | Program pendeteksi dan penghapus perangkat lunak jahat, misalnya Windows Defender (bawaan), Kaspersky, ESET, ClamAV (Linux). | Lapisan perlindungan dasar setiap komputer klien. |
| 54 | **Firewall Host (Windows Firewall, ufw, iptables)** | Firewall bawaan OS yang menyaring koneksi masuk/keluar komputer. ufw adalah antarmuka sederhana iptables/nftables di Ubuntu. | Melindungi komputer/server dari akses tidak sah; sering penyebab "ping tidak balas" padahal jaringan normal. |
| 55 | **Remote Desktop (RDP) dan VNC** | Mengendalikan tampilan komputer lain dari jauh. RDP (port 3389) bawaan Windows Pro; VNC lintas platform; alternatif: AnyDesk, TeamViewer, Chrome Remote Desktop. | IT support membantu pengguna tanpa harus datang. |
| 56 | **SSH Client (PuTTY, OpenSSH, Termius)** | Aplikasi untuk mengakses terminal server/perangkat jaringan dari jauh secara terenkripsi (port 22). Windows 10+ sudah punya `ssh` di CMD/PowerShell. | Cara utama mengelola server Linux dan router. |
| 57 | **Virtualisasi Desktop (VirtualBox, VMware Workstation)** | Aplikasi hypervisor tipe 2 untuk menjalankan OS lain di dalam Windows/Linux, dengan fitur snapshot dan jaringan virtual (NAT, Bridged, Host-only, Internal). | Laboratorium pribadi untuk latihan instalasi OS, server, dan topologi jaringan tanpa perangkat tambahan. |
| 58 | **Snapshot dan Clone (VM)** | Snapshot: menyimpan kondisi VM pada satu titik agar bisa dikembalikan. Clone: menggandakan VM menjadi VM baru. | Bereksperimen tanpa takut rusak; membuat banyak server latihan dengan cepat. |
| 59 | **Mode Jaringan VM (NAT, Bridged, Host-only, Internal)** | NAT: VM ikut internet host lewat IP tersembunyi. Bridged: VM tampil seperti komputer terpisah di LAN nyata. Host-only: hanya bisa bicara dengan host. Internal: hanya antar-VM. | Memilih skenario jaringan lab yang tepat, misalnya Bridged agar VM bisa diakses dari LAN. |
| 60 | **32-bit vs 64-bit (x86 / x64) dan ARM** | Lebar data prosesor dan OS. 64-bit mendukung RAM lebih dari 4 GB dan lebih cepat. ARM adalah arsitektur hemat daya (HP, Raspberry Pi, Apple M-series). | Memilih ISO dan aplikasi yang sesuai arsitektur perangkat. |
| 61 | **Multitasking, Multiuser, dan Multiprocessing** | Multitasking: banyak program berjalan bersamaan. Multiuser: banyak pengguna memakai sistem sekaligus (khas Linux/server). Multiprocessing: memanfaatkan banyak core CPU. | Menjelaskan mengapa Linux cocok sebagai server yang melayani banyak pengguna. |
| 62 | **Aplikasi dan Utilitas** | Aplikasi: program untuk pengguna (browser, office, Packet Tracer). Utilitas: program pembantu pemeliharaan sistem (disk cleanup, defrag, CCleaner, GParted). | Melengkapi OS agar produktif dan terawat. |
| 63 | **Browser dan Cloud Storage** | Browser (Chrome, Firefox, Edge) mengakses web; cloud storage (Google Drive, OneDrive, Nextcloud) menyimpan file di internet. | Alat kerja harian dan cara aman menyimpan salinan dokumentasi jaringan. |
| 64 | **Simulator Jaringan (Cisco Packet Tracer, GNS3, EVE-NG, Winbox + CHR)** | Perangkat lunak untuk merancang dan menguji jaringan secara virtual. Packet Tracer ringan untuk belajar Cisco; GNS3/EVE-NG menjalankan image router asli (termasuk MikroTik CHR). | Berlatih topologi, VLAN, routing, dan server tanpa perangkat fisik. |
| 65 | **Wireshark** | Aplikasi penganalisis paket (packet analyzer/sniffer) open source yang menangkap dan menampilkan isi lalu lintas jaringan lapis demi lapis. | Belajar protokol secara nyata dan menemukan penyebab gangguan/serangan. |
| 66 | **Zona Waktu dan NTP Client** | Pengaturan zona waktu (Asia/Jakarta, WIB = UTC+7) dan sinkronisasi jam otomatis lewat internet (NTP). | Jam yang salah menyebabkan sertifikat HTTPS ditolak, log membingungkan, dan login domain gagal. |
| 67 | **Aktivasi dan Product Key** | Proses mengesahkan lisensi Windows/Office dengan kunci produk atau akun digital. | Sistem berlisensi legal mendapat pembaruan penuh dan tidak melanggar hukum. |
| 68 | **Instalasi Driver Jaringan** | Memasang driver LAN/Wi-Fi setelah instalasi OS (dari CD motherboard, situs vendor, atau Windows Update); di Linux umumnya sudah tertanam di kernel. | Tanpa driver jaringan, komputer tidak bisa terhubung meski kabel terpasang. |
